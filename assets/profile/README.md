# 主页视觉素材

这些素材服务于个人主页的身份与代表作展示，详细系统架构继续放在对应项目文档中。所有图片、说明和引用都在 AI 可编辑区域之外。

## 原创横幅

- 首屏保留深浅色原创横幅，并在图片下用普通文本说明专业能力与代表项目。
- `banner-light.svg` / `banner-dark.svg`：960 × 190，构图一致，使用系统字体、内嵌颜色与路径。无脚本、外部字体或网络资源。
- 主题是工具开发与验证记录。括号、代码短线和勾形笔画属于抽象插画，不是实际产品界面或架构。
- 横幅文案分三层：AI 应用工程与 Agent 工作流；模型接入、工具编排、自动化测试与结果验证；sqlseed 作者 / 维护者及相关技术。文字与当前公开实践一致，不展示个人职业状态。
- 姓名、能力方向及项目事实仍保留在 README 的普通文本中。

## 维护边界

现有 AI 维护流程只修改 README 中指定的公开文字区域，不会自动生成、重绘或替换这些素材。后续新增项目截图，需要本人确认展示时机、公开版本和可用测试数据。
